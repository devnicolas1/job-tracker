# Agent instructions

Read `CLAUDE.md` for project rules; they apply to every agent, not only Claude.

Workflows (use the `job-tracker` MCP server; see `README.md` to register it):

- To find jobs, follow `.claude/skills/find-jobs/SKILL.md`.
- To fill the profile from an uploaded résumé, follow `.claude/skills/import-resume/SKILL.md`.
- To tailor the résumé for one tracked job (`/tailor-resume <job id>`), follow
  `.claude/skills/tailor-resume/SKILL.md`.
